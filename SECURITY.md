# Security

If you find a security problem (for example in sign-in, sync or data rules), please do not post it publicly.
Open a private security advisory on this repository (Security tab, "Report a vulnerability") or message the owner, Darshankumar Savsani, through his GitHub profile.

These apps keep data on your own device, and optionally in your own Google account when you turn on sync. Never share your passwords or tokens in an issue.
